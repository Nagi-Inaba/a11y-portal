# オフ会成果報告スライド

- `02-slides.html`：発表用。画像・スタイル・発表操作を内包した単一HTML。ブラウザで開く。
- `01-slides.md`：編集用Marpソース。本文6枚と出典1枚、発表者ノート付き。
- `assets/`：2026年9月13日に公開サイトから取得した実画面。架空データを表示している。
- `03-slide-brief.md`、`05-deck-working-note.md`：構成と出典照合の記録。

## 操作

左右の矢印キーで移動。画面下のコントローラーから全画面表示・発表者ビューを利用できる。出典リンク以外はオフラインで使用できる。

## 再生成

Node.js 22とMarp CLI 4.5.0で作成。Marp CLIが導入済みの環境で、このディレクトリの`04-build.ps1`を実行する。アプリ本体の依存パッケージは変更しない。

```powershell
./04-build.ps1
```

未導入の場合は、[Marp CLIの公式手順](https://github.com/marp-team/marp-cli)に従って`@marp-team/marp-cli@4.5.0`を用意する。
